🧑‍⚕️ Build Your Professional Visual Identity

สร้าง “Identity Kit” และ Master Visual เพียงครั้งเดียว แล้วใช้เป็น reference ต่อใน Infographic, Slide Cover, Quote Card, Media Visual และชุดภาพหลายฉาก เพื่อให้สื่อของคุณมีตัวตนที่ต่อเนื่อง

✨ REUSE PROMPT
หลักสำคัญ: รอบแรก Master Image Prompt สั่งให้ AI สร้างภาพจาก Identity Kit ซึ่งเป็น Context เมื่อได้ภาพแล้ว รอบต่อ ๆ ไป ภาพ Master Visual + Identity Kit คือ Context/Reference ส่วน Prompt ใหม่มีหน้าที่บอก R–T–F ของสื่อที่จะสร้าง
💡 Prompt ≠ Context ใน Workshop นี้ Prompt คือคำสั่งที่บอก AI ว่าให้รับบทอะไร ทำอะไร และตอบแบบไหน (R–T–F) ส่วน Context คือข้อมูลที่เรามีแต่ AI ยังไม่รู้ เช่น บันทึกประชุม เหตุการณ์ ข้อเท็จจริง เอกสารต้นทาง ตัวเลข หรือ feedback — จึงตั้งใจแยกสองส่วนนี้ออกจากกันให้ชัด

PAGE 2 · CASE-BASED MEDICAL COMMUNICATION

Medical Communication Lab — แต่ละงานมี Context ของตัวเอง

แต่ละกิจกรรมด้านล่างมี Context / Source ของตัวเอง ผู้เรียนจึงเลือกทดลองเป็นรายกรณีได้ทันที โดย Context จะทำหน้าที่เป็น “ข้อมูลต้นทาง” เท่านั้น ส่วนคำสั่ง วิธีคิด และรูปแบบคำตอบจะอยู่ใน Prompt R–T–F

📎 Trusted Source First: ให้ AI เริ่มจากข้อมูลที่องค์กรยืนยันแล้ว ไม่ใช่เริ่มจากสิ่งที่ AI จำมาเอง หาก Context ไม่ได้ให้ข้อมูลบางเรื่อง ต้องระบุว่า “ข้อมูลไม่เพียงพอ / Source ไม่ได้กำหนด” แทนการเติมข้อเท็จจริงเอง
